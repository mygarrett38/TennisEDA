# TennisEDA

Exploratory data analysis of the Tennis Abstract Match Charting Project.

- `tennis_db.py` builds a SQLite database (`tennis.db`) from the charting CSVs.
- `eda_tennis.py` reads that database, prints summary tables, and displays charts.

Built for data analysis for CIS 399 course at Shepherd University.
